记住这条边界

LLM 返回 tool_use 是请求执行。真正调用函数、检查权限、拼接 tool_result 的是 Agent 程序。

协议速查 CHEAT SHEET

system

角色、行为约束与运行环境

messages[]

用户输入、模型响应、工具结果

tools[]

工具名称、说明、输入 Schema

tool_use.id

配对 tool_result.tool_use_id

max_tokens

本次模型输出的 token 上限

stop_reason

响应结束原因；循环还会检查内容块

一行代表一个可观察事件。先看箭头的发送方与接收方，再看右侧 JSON。真实模式中，LLM 请求的 messages 是发送时的快照；call_id 对齐请求与响应，线程名区分后台执行。
高级章节的教学场景是关键事件节选，并不包含每次完整请求；不会把缺少的上下文补成真实记录。完整参数请在真实模式中查看。
